# CheckMates – Connected Chessboard Project

## Description

**CheckMates** is an innovative project developed by a team of engineering students from **CentraleSupélec**.
The goal of the project is to design and build a **connected physical chessboard** that allows people to:

* Play chess **remotely** with another person using two synchronized physical boards.
* Enable **people with reduced mobility** to play chess with someone physically present through an intelligent, assistive interface.

The project combines **electronics, mechanics, and software engineering** to deliver a seamless experience between the physical and digital worlds.
This repository contains the **web interface** of the CheckMates platform, built using **React.js**.

---

## Features

* Presentation of the CheckMates project and team
* Responsive, modern web interface built with **React**
* Modular styling using **SCSS modules**
* Integration with future back-end services (e.g., real-time board synchronization, user accounts)
* Easy to extend and deploy across multiple devices

---

## Technologies Used

* **React.js** – Front-end framework
* **SCSS Modules** – Component-level styling
* **Create React App** – Project setup and development environment

## Installation and Setup

1. **Clone the repository**

   ```bash
   git clone https://github.com/your-username/checkmates.git
   cd checkmates
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Run the development server**

   ```bash
   npm run dev
   ```

4. Open your browser and go to:

   ```
   http://localhost:5173
   ```
